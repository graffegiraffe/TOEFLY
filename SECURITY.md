# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through
[GitHub private vulnerability reporting](https://github.com/graffegiraffe/TOEFLY/security/advisories/new).

Include what is affected, how to reproduce it and the impact you expect. You will get an
answer within 7 days, and a fix or mitigation plan once the report is confirmed.

## Supported versions

TOEFLY is in active development. Security fixes go to the latest release.
